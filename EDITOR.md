- Same game engine w/ dev utilities on top.
- Dev can toggle on and off the jump arc (min & max)
- Full screen width with game play window highlighted in the center (to allow
  for wider map editing)
- Dev can scroll left & right as needed, up to goal screen.
- Dev can add platforms & obstacles by clicking and dragging.
- Dev can edit existing platforms & obstacles by dragging their corners
- Dev can delete platforms & obstacles.
- Dev can expand the playable field by setting the game width.
- Dev can reposition the hero to any location they want with a click.
- Dev can play from wherever the hero is set, and the game with reset back to
  the editor with the hero in the same position, when finished.
- Dev can save and name the level as JSON (copy paste to persist locally)
